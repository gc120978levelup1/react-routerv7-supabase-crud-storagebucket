
1. Install Supabase CLI using npm, Create a folder
npm install supabase
npx supabase init
npm install supabase --save-dev

2. Open Docker Desktop. 
   Setings-> Enable, Expose Daemon on tcp://localhost:2375 w/o TLS

   npx supabase start -x logflare --debug

3. Wait for Docker to install everything. Around 11 docker container will be downloaded
   including pg, supabase admin and supabase servers. When all OK and installed

4. Login to cli, press enter it will launch webapp to give token number to be entered
   during login. 
npx supabase login

5. Link to Online supabase project using project code. 
npx supabase link --project-ref vwvfwocctkedccoksmta

ex,
VITE_SUPABASE_URL=https://vwvfwocctkedccoksmta.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_rnU92lVz5wMiBZrmMb1CmQ_zQRXdbZQ

therefore, use project reference, vwvfwocctkedccoksmta as parameter

6. migration files

# remote -> local
npx supabase migration list --remote
npx supabase migration repair --status reverted <REMOTE_MIGRATION_VALUE> --remote
npx supabase db pull --remote
npx supabase db dump --remote --data-only -f supabase/seed.sql
npx supabase db reset --local
npx supabase db dump --remote --data-only --schema auth -f supabase/seed.sql
npx supabase db reset --local

# local -> remote
npx supabase db pull --local
npx supabase db dump --local --data-only -f supabase/seed.sql
npx supabase db reset --remote
npx supabase db dump --local --data-only --schema auth -f supabase/seed.sql
npx supabase db reset --remote

7. open in chrome http://localhost:54322/
to open local supabase web client

8. goto http://127.0.0.1:54323/project/default/sql
  SQL edit to copy and paste the sql output of # 6, pull request dump file

9. that time, if all ok the database structure is copied on local pgsql

10. logout/stop 
npx supabase stop --no-backup --debug
docker ps -aq | xargs docker stop | xargs docker rm
